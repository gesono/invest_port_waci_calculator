# Data

This folder intentionally contains no real fund data.

Carbon figures on fund factsheets and reports are frequently licensed from third-party ESG data providers, whose terms usually restrict redistribution. To keep this repository safe to share publicly:

- the calculator ships only fictional example funds;
- users enter figures they have access to themselves, and those figures stay in their own browser;
- any private or licensed data used for local development belongs in `data/private/`, which is excluded by `.gitignore`.
